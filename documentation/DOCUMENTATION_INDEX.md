## 🎯 Critical Demo Scripts (Copy-Paste Ready)

### Demo 1: Bell State (Best for showing entanglement)
```
"Let me create quantum entanglement. This is one of the most fascinating 
quantum phenomena."

[Click Templates] → [Load Bell State] → [Run Simulation]

"Notice how the two qubits are connected (purple line). When we measure one, 
it instantly determines the other - without any classical communication. Einstein 
called this 'spooky action at a distance.'"
```

### Demo 2: Superposition (Best for showing basics)
```
"Let's start simple. The Hadamard gate creates quantum superposition."

[Drag H gate to qubit] → [Run Simulation]

"See the probability bars? 50-50 chance of measuring 0 or 1. The qubit is 
literally in both states simultaneously until we measure it."
```

### Demo 3: Measurement Collapse (Best for showing randomness)
```
"Quantum mechanics is probabilistic. Watch what happens when we measure."

[Load Measurement template] → [Run multiple times]

"Each run gives different results! This randomness is fundamental - we can't 
predict individual outcomes, only probabilities."
```
